# Agent instructions

This folder is a self-contained recipe for one video format: the airy launch film (white canvas, cloud-mask reveal, felt-puppet cast, glowing app windows, word wheel; music only). Read `PLAYBOOK.md` here fully before doing anything.
Start from a copy of `template/`. Format-specific scripts are in `tools/` (`cutout_keyed.py`, `el_audio.sh`); shared scripts are in `../tools/`. The overview of all formats is `../PLAYBOOK.md`.
