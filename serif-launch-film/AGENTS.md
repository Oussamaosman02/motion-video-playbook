# Agent instructions: serif launch film

This folder is a self-contained recipe for a 9:16 "premium launch film": navy glow + pale studio chapters, italic serif × heavy sans lines, glowing pill keywords, 3D UI cards, an orbit of tiles, a cycling-word showcase, a strike-through list and a logo end card. Music only, no voiceover, no AI video.
Read `PLAYBOOK.md` fully before doing anything.
Start from a copy of `template/` (HyperFrames 0.8.137: `npm run check`, `npx --yes hyperframes@0.8.137 snapshot|render`).
Format-local scripts: `tools/el_audio.sh` (sequential ElevenLabs music/SFX with 429 backoff), `tools/split_grid.py` (split a Gemini photo grid). Shared scripts live in `../tools/` (don't edit them from here).
