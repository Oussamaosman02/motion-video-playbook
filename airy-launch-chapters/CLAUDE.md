# Agent instructions

This folder is a self-contained recipe for one video format: the airy launch film, "chapters" variant (Manus 2.0 style). It has soft grey chapter cards with a line icon, frosted glass cards over serene landscape photos, a lifting dock row of question tiles, a crowd of code-built SVG mascots around a black pill, a black vertical word ticker and a phone offer. It is music only, with the script as on-screen text.
It is a variant of `../airy-launch/` (F6): read `../airy-launch/PLAYBOOK.md` first, then `PLAYBOOK.md` here, which documents only the differences.
Start from a copy of `template/`. Shared scripts are in `../tools/` (`gen_image_ar.py` for the 9:16 landscapes, `el_audio.sh` for music/SFX, which is sequential with 429 backoff and uses a shared key). The overview of all formats is `../PLAYBOOK.md`.
