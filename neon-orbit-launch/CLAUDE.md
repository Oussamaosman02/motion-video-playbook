# Agent instructions

Format V, neon orbit launch film (voice, 28 s). Read `PLAYBOOK.md` fully, start from a copy of `template/`, retime scenes with the `SC` table (VO word indexes) and regenerate audio tags with `tools/build_audio.py` (copy it into the project's `tools/`). Shared helpers (`gen_image_ar.py`, `cutout_grid.py`, `fit_music.sh`, `sfx_normalize.sh`) are in `../tools/`. Never TTS when a VO can be reused; keep all art original (no logos, flags, platform emoji or real faces).
